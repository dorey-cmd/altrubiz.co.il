### Quick Reminders:
1. **Never hardcode routes**: All routes are declared in `src/lib/routes.ts` or `src/data/articles.ts`.
2. **Never skip validation**: Always run `npm run test:geo` before completing any routing or content task.
3. **Build pipeline is strictly guarded**: `npm run build` will fail if any GEO requirement or canonical link is broken.
4. **LLM Mirrors**: When creating or modifying articles, run `npm run articles:sync-md` (or run `npm run build` which runs it automatically).
5. **Always Unisex Phrasing**: All copy, buttons, and UI must be naturally gender-neutral without slashes (no `קרא/י` etc.). See [`.agents/rules/unisex-copy-standard.md`](file:///c:/Users/Dorey/Documents/Vibe/altrubiz.co.il/.agents/rules/unisex-copy-standard.md).
6. **Always Business-Oriented Alt-Texts**: Never describe image art mediums (no `פלסטלינה`, `איור` וכו'). Alt texts must faithfully reflect search terms, business situations, or CRM mechanisms.
7. **Brand Attribution & Authorship**: General system content is attributed to `צוות אלטרוביז` / `צוות AltruBiz` or `אלטרוביז`. Personal attribution (founders, experts, case studies) is permitted and welcomed when it reinforces authenticity, authority, and E-E-A-T.
8. **Contextual CTA Formula**: Follow $\text{Context} \rightarrow \text{Action} \rightarrow \text{Message} \rightarrow \text{Mechanism} \rightarrow \text{Attribution}$. Use presentation patterns (`strip`, `quote-share`, `text-link`, `pricing`, `box`) based on narrative relevance, not rigid quotas. See [`.agents/rules/article-cta-standard.md`](file:///c:/Users/Dorey/Documents/Vibe/altrubiz.co.il/.agents/rules/article-cta-standard.md).
9. **Connected Knowledge Topology**: Operate as a connected knowledge graph centered around business pains. Classify all nodes in `src/data/knowledgeGraph.ts`, link bidirectionally (inbound + outbound), promote Hubs strictly via qualitative knowledge maturity and genuine user value (zero numerical quotas), and never leave dead-end pages. See [`.agents/rules/knowledge-topology-architecture.md`](file:///c:/Users/Dorey/Documents/Vibe/altrubiz.co.il/.agents/rules/knowledge-topology-architecture.md).
10. **Dual Operating System (Knowledge OS + Design OS)**: Comply with both Knowledge OS (semantic meaning & relevance) and Design OS (visual language, living interface, comfortable reading width, and anti-generic-AI guardrails). See [`.agents/rules/design-operating-system.md`](file:///c:/Users/Dorey/Documents/Vibe/altrubiz.co.il/.agents/rules/design-operating-system.md).
11. **Contextual Semantic Linking & Progressive Knowledge UX**: The body text itself is part of graph navigation. Invariant: **"LINK FOR UNDERSTANDING, NOT FOR OCCURRENCE."** Never link automatically on keyword matches. Common words remain clean prose. Progress from link to short definition to Hub. Node existence $\neq$ page existence (Public Page Eligibility = Qualitative Knowledge Maturity + Genuine User Value; zero numerical quotas). No numerical link quotas. Same-window navigation (`target="_self"`). See [`.agents/rules/contextual-semantic-linking.md`](file:///c:/Users/Dorey/Documents/Vibe/altrubiz.co.il/.agents/rules/contextual-semantic-linking.md) and authoritative specification [`.agents/specs/contextual-semantic-linking.md`](file:///c:/Users/Dorey/Documents/Vibe/altrubiz.co.il/.agents/specs/contextual-semantic-linking.md).
12. **Publication Readiness & Indexability Control**: Strictly distinguish $\text{Knowledge Maturity} \neq \text{Public Page Existence} \neq \text{Publication Readiness} \neq \text{Indexability}$. One Knowledge Graph + Controlled Public Projection. Zero automatic publishing or indexing upon ingestion. Sitemap contains only approved indexable canonical destinations. Accessible review pages receive `noindex, follow`. Canonical identity $\neq$ indexability. See [`.agents/rules/publication-indexability-governance.md`](file:///c:/Users/Dorey/Documents/Vibe/altrubiz.co.il/.agents/rules/publication-indexability-governance.md) and authoritative specification [`.agents/specs/publication-indexability-governance.md`](file:///c:/Users/Dorey/Documents/Vibe/altrubiz.co.il/.agents/specs/publication-indexability-governance.md).
13. **Question-to-Answer Link Policy & Graph Single Source of Truth**: Never use generic anchor labels (`לקריאה`, `קרא עוד`, `למידע נוסף`). Links must articulate the substantive answer, promise, or diagnostic inquiry. Presentation components query `src/data/knowledgeGraph.ts` via selectors (`getApprovedPublicHubs`, `getCanonicalRecognitionSituations`, `getFeatureKnowledgeLink`, `getHowItWorksStepKnowledge`) without maintaining duplicate maps.
14. **Markdown Link Dynamic Rendering**: Editorial markdown links (`[anchor](url)`) are rendered as internal client `<a>` tags with `target="_self"`, preserving SPA navigation and back-button history.
15. **Mobile First-Class Knowledge UX**: Compact vertical rhythm, early navigation discovery via bottom-floating pill appearing at `scrollY > 200`, bounded touch modals (`max-h-[90vh]`), and inverted header hierarchy (keeping H1 above the fold).
16. **Strict Meeting vs. Contact Separation & Structured Attribution**: Never route a Meeting/Consultation CTA to a Contact form. Meeting CTAs MUST open `BookingModal`; Contact CTAs open `ContactModal`. Every CTA transmits structured telemetry (`CTAContext`) to GHL iframes via UTM parameters and to WhatsApp prefilled links.
17. **Scroll Sovereignty Invariant**: "Navigation follows the reader - never the reverse." The user's document scroll position is sovereign. Passive active-section tracking may ONLY scroll the sidebar's internal container (`container.scrollTo`), never calling `scrollIntoView()` which alters document/window scroll position. Explicit user clicks on TOC items scroll the document; passive tracking never does.
