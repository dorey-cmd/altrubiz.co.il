# תקן שפה שוויונית ונייטרלית מגדרית (Unisex Copy Standard)

מסמך זה מהווה דרישת חובה קבועה לכל תוכן, ממשק, כפתור, מאמר, תווית או הודעה באתר **AltruBiz CRM** (`altrubiz.co.il`).

---

## 1. עקרון יסוד: עברית שוויונית וטבעית
יש לנסח את כל התכנים באתר כך שיפנו וידברו לשני המינים בצורה טבעית, זורמת ומכבדת, ללא שימוש בהטיות מגדריות חד-מיניות (לשון זכר בלבד או לשון נקבה בלבד) וללא תבניות מנוכרות או מגושמות.

---

## 2. איסור מוחלט על לוכסנים וסימנים מיוחדים
❌ **אסור בהחלט להשתמש בלוכסנים או נקודות**:
- לא: `קרא/י`, `הצטרף/י`, `לחץ/י`, `השאר/י`, `שלח/י`
- לא: `קרא.י`, `הצטרף.י`, `שלח.י`

ניסוחים כאלה פוגעים בקריאות (Readability), בחוויית המשתמש (UX) ובסריקת מנועי חיפוש ו-LLM.

---

## 3. דרכי הניסוח המומלצות (Best Practices)

### א. שימוש בשמות פועל (Infinitives) עבור כפתורים ופעולות:
- במקום `התחל עכשיו` / `התחל/י` ➔ **`להתחיל עכשיו`** או **`מתחילים עכשיו`**
- במקום `קרא את המאמר` / `קרא/י` ➔ **`לקריאת המאמר`** או **`קריאת המאמר`**
- במקום `הצטרף עכשיו` ➔ **`להצטרפות`**
- במקום `צור קשר` ➔ **`ליצירת קשר`** או **`דברו איתנו`**
- במקום `לחץ כאן` ➔ **`למעבר`** / **`לקביעת פגישה`**

### ב. שימוש בשמות פעולה (Nominal Forms):
- במקום `השאר פרטים ונחזור אליך` ➔ **`השארת פרטים ונחזור אליכם בהקדם`**
- במקום `השווה את כל התכונות` ➔ **`השוואת כל התכונות`**
- במקום `בחר מסלול` ➔ **`בחירת מסלול`** / **`המסלול המתאים לעסק`**
- במקום `סגור חלון` ➔ **`סגירת חלון`**

### ג. שימוש במבנים סתמיים ומשפטים פסיביים (Impersonal / Passive):
- במקום `מה אני יכול לעשות עכשיו?` ➔ **`מה אפשר לעשות עכשיו?`**
- במקום `תוכל לראות` ➔ **`ניתן לראות`** / **`אפשר לראות`**
- במקום `אם תרצה לקבל` ➔ **`לקבלת פרטים נוספים`**
- במקום `אתה לא צריך ללמוד` ➔ **`אין צורך ללמוד`** / **`לא צריך ללמוד`**

### ד. פנייה בלשון רבים / פנייה כוללת (Collective Plural):
- **`ברוכים הבאים!`** (קבלת פנים עסקית מקובלת וטבעית)
- **`רוצים לשמוע עוד?`**
- **`לא בטוחים מאיפה להתחיל?`**
- **`צוותי מכירות ושירות`**, **`בעלי ובעלות עסקים`**, **`מנהלי ומנהלות שיווק`**

---

## 4. מילות מפתח לבדיקה בכל שינוי עתידי
בכל עריכת תוכן או יצירת רכיב חדש, יש לבצע בדיקה ולוודא שאין:
- `אתה` / `את`
- `תוכל` / `תוכלי` (להחליף ב-`ניתן` / `אפשר`)
- `תקבל` / `תקבלי` (להחליף ב-`מקבלים` / `קבלת`)
- `השאר` / `השאירי` / `השאר/י` (להחליף ב-`השארת פרטים`)
- `קרא` / `קראי` / `קרא/י` (להחליף ב-`לקריאה` / `קריאת המאמר`)
- `בחר` / `בחרי` / `בחר/י` (להחליף ב-`בחירה` / `לבחירת`)
- לוכסנים `/` בתוך מילים
